## S16. The flip is five lines, each a step done by hand
*What does a coin per member look like in code?*

```python
diffs = [a - b for a, b in zip(q1, q2)]    # each member's Q1 less Q2
for _ in range(5000):                       # 5,000 chance-only worlds
    coins = [d if random.random() < 0.5 else -d for d in diffs]
    gaps.append(mean(coins))                # heads keeps, tails swaps
share = sum(g >= real for g in gaps) / 5000
```

The last line counts the worlds with a gap at least as large as the real one, which is the share the cards counted by hand.
