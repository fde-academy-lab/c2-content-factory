# Mid-session: defensible, or wrong?

Six sentences. For each, decide whether it is a defensible statement of the result, or one of the
readings that reverses what a p-value means.

Post one line with your six letters in item order.

```
Post exactly this shape: xxxxxx
```

---

## Q1. "Chance alone produced a gap this large in none of 5,000 shuffles."

Which one?

a) Defensible, since it states the result and the resolution
b) Wrong, because a count of zero should be reported as a probability of zero
c) Wrong, because it does not give a p-value at all in numeric form
d) Defensible only if five thousand shuffles is the accepted standard number

---

## Q2. "p equals 0.03, so there is a 3 percent chance we are wrong."

Which one?

a) Defensible, since that is how the number is used in practice everywhere
b) Wrong, it describes the conclusion and not the worlds
c) Defensible if the sample is large enough for the approximation to hold
d) Wrong, because 3 percent should have been written as 0.03 for clarity

---

## Q3. "The p-value is small, so the effect is large."

Which one?

a) Defensible, because small p-values arise from large differences
b) Defensible when the sample size is held constant across both groups
c) Wrong, it confuses whether chance did it with how big it is
d) Wrong, because the effect size should be reported as a percentage

---

## Q4. "p is 0.383, so Student is flat."

Which one?

a) Defensible, since a large p-value means there is no real difference
b) Wrong, it turns no evidence into a finding of nothing
c) Defensible if the twelve orders are a complete census of the segment
d) Wrong, because the correct phrase is that the result is insignificant

---

## Q5. "The fall is real, so we should act on it."

Which one?

a) Defensible, since a real finding is by definition worth responding to
b) Defensible once the p-value is below the conventional 0.05 threshold
c) Wrong, because no action should follow from a single quarter of data
d) Wrong, real and worth acting on are separate calls

---

## Q6. "We do not know yet, and a full quarter at about fifty orders would tell us."

Which one?

a) Wrong, a CEO asked for an answer and this gives them nothing usable
b) Wrong, because promising a future answer commits you to a timeline
c) Defensible, and it names the thing that would change the answer
d) Defensible only when there is no number at all available to report
