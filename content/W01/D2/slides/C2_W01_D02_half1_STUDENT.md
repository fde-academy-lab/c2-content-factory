## S14. One dictionary adds revenue up by quarter
*How does one pass over the orders total each quarter?*

```python
# ORDERS: the export, one dictionary per booked order
revenue = {}     # quarter -> rupees booked
orders = {}      # quarter -> number of orders
for order in ORDERS:
    q = order["quarter"]
    if q not in revenue:
        revenue[q] = 0
        orders[q] = 0
    revenue[q] += order["amount"]
    orders[q] += 1
change = (revenue["Q2"] - revenue["Q1"]) / revenue["Q1"] * 100
```

**The rule.** A key seen for the first time starts at zero, and every order adds to its own quarter. This accumulator is the tool the whole day grows.

def tree_for(rows):
    """Revenue, orders, customers and the two rates for any group of orders."""
    revenue, seen = 0, {}
