# Day 1 exercises

Four pieces of work, in the order they run.

| When | File | Shape | You answer with |
|---|---|---|---|
| With the trainer | `guided/C2_W01_D01_first_leaves_STUDENT.md` | Built together, line by line | Your own notebook, mirrored |
| Mid-session | `unguided/C2_W01_D01_predict_output_STUDENT.md` | Predict before you run | Six letters, posted as one string |
| Second half, alone | `unguided/C2_W01_D01_branch_choice_STUDENT.md` | Read the tree, choose and defend | Six letters plus one sentence |
| Tonight | `../takehome/C2_W01_D01_brief_STUDENT.md` | A second file nobody has seen | A notebook and a note |

Solutions to the two unguided sets are released at the close of the session and live in
`solutions/`. The take-home solution opens tomorrow's session.

**Answer format for both unguided sets.** One line, six letters, no spaces, in item order. The
letters shown in the format example are `x` on purpose, so the example never carries an answer.

```
Post exactly this shape: xxxxxx
```
