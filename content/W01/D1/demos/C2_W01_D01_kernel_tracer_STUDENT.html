Kalpa kernel tracer

Week 1, Day 1. The kernel is a workbench that keeps exactly what you put on it. This page runs the four cells in whatever order you choose, so you can watch a name arrive, watch it go at a restart, and watch a comparison refuse a value it cannot read honestly.

Guided walk

Four cells, run in the order you click them

Press Next once per cell. The drawing lights the cell that just ran, the bench underneath shows what the kernel is holding, and the meter fills one tick per cell that has run. Click the meter for the breakdown of why each tick is marked as it is.

Experiments

      
Change one thing and watch what moves

      
Each card changes exactly one thing and leaves everything else alone. Pick an option, press the run button, and the card fills in what happened, why it matters and the rule it leaves you with. The sequence button draws the same run across the lanes it travelled.
