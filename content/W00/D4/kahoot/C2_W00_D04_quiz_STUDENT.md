# Kahoot, Week 0 Day 4

Five items on the warden's mess, ungraded, scored on correctness and speed together, so the mechanic
is familiar before Week 1 Monday. There is no return question in Week 0.

Each item names what it tests, so a trainer who is short of time can drop one and know what was
lost.

---

## Q1. "An app that predicts how many students will eat" is which?
*Tests: telling the stated problem from the real one.*

a) The real problem, because it names the thing to build
b) The stated problem: a solution arriving with the ask  <- correct
c) The number that would move, since it counts students
d) A constraint, because the mess has to use an app

---

## Q2. "The vendor bills for every plate ordered, eaten or not." The mess manager said it.
*Tests: known means someone who would know has said it.*

a) Known, since someone who would know has said it  <- correct
b) Assumed, since nobody has shown the vendor's bills
c) Must ask, since only the vendor can confirm it
d) None of them, since it is a cost and not a fact

---

## Q3. "Students would use an app to say they are skipping dinner."
*Tests: assumed means nobody has checked it.*

a) Known, since most students carry a phone all day
b) Must ask, since only the warden can decide it
c) Known, since the mess manager suggested it
d) Assumed, since no student has been asked  <- correct

---

## Q4. Which question comes first, before any option is discussed?
*Tests: the number that would move comes before any tool.*

a) Which app framework would suit a mess of this size?
b) How many plates go to waste, and on which nights?  <- correct
c) How accurate would a prediction model need to be?
d) Could the vendor deliver twice a day instead of once?

---

## Q5. The cheapest fix may need no model. Which option uses none?
*Tests: at least one option on the table has no model in it.*

a) An app that forecasts attendance from last term's data
b) A model that learns each student's dinner habits
c) A sign-out each morning on the mess group  <- correct
d) A chatbot that asks students every afternoon
