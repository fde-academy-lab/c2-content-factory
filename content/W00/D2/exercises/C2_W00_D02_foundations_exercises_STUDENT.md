mini project inside the hands-on minutes the guide gives the chapter. Each has a guided file you work
in and a solution beside it, and each feeds one of the mini project repositories that the Chapter 8

Work in the guided file and keep the solution closed. A guided notebook is a TODO twin: run it from
the top and it stops at the first placeholder with a `NameError`, which is where you start, and each
placeholder is either a lettered choice whose code you type in its place or a prediction you write
before the cell that tests it runs, with a check under every step that says whether you were right.
The Excel workbook's yellow cells and the GitHub walkthrough's steps work the same way, with the
Checks sheet and the checker's report as the checks. Open the solution when a check still fails after
a second look at its step, or once everything runs clean, to compare your work with it; a solution
notebook adds a line under each step on why the other options fail.
