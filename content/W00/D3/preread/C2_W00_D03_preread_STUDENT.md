## Tonight: the librarian's weekly report

The librarian wants all three answers from one call. In the notebook where you typed the class log
today, write a function `weekly_report(log)` that returns a dictionary holding the number of issues,
the busiest department and the days late past the 14-day loan.

For the class log it returns exactly this, which is your check:

```python
{"issues": 8, "busiest": "Maths", "late_days": 13}
```

If you have the hands-on notebook, its last step is the same task on the next week's log, and its own
check tells you when you are right. Either way, post the letters you have and the line your function
printed.

Three things trip this task up, and each one was in today's class: a function that prints its answer
instead of returning it, a running total started inside the loop, and a list counted from 1.
