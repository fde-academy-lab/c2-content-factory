# Monday's exercises

Three pieces, in the order they are met. The guided one is built with the room, the two unguided
ones are yours alone, and the solutions arrive at close of session.

| Piece | Where | What it asks |
|---|---|---|
| Guided: the first aggregate | `guided/C2_W02_D01_first_aggregate_STUDENT.md` | Build one grouped query together, narrating the execution order at each step |
| Unguided: predict the row count | `unguided/C2_W02_D01_row_count_STUDENT.md` | Say how many rows four queries return before running any of them |
| Unguided: put the clauses in order | `unguided/C2_W02_D01_clause_order_STUDENT.md` | Order five clauses by when they run, and defend one placement |
| The suite | `../sql/C2_W02_D01_02_monday_suite_STUDENT.sql` | Six queries with their comment lines, no hints |

The suite is the day's deliverable. The two unguided pieces are the ten minutes that decide
whether you can write it without guessing.
