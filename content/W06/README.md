# Week 6: Build 2 at Kalpa Financial

One shared problem for all 13 groups, from black box to defence: whom should Kalpa's team call
before the due date, when a missed default costs about five times a wasted call? The proof runs on a
public card book (UCI Default of Credit Card Clients, CC BY 4.0), and each group's constraint card
changes its answer. The whole week ships as one pack, handed out on Tuesday:
[D2/README.md](D2/README.md).
