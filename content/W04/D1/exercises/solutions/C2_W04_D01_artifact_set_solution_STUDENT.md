## What does the set test about the metric definition artifact?

The page has seven lines: four that make the number computable (numerator, denominator, window,
exclusions) and three that make it safe to pay for (what it does not reward, the guardrails, the
gaming note). A target is no line at all. When teams disagree, the page settles it by pointing at a
line, or by changing one line and dating the change.

## Which item is worth arguing about?

Item 3, option a. Turning the losing team's number into a guardrail feels generous, which makes it
the tempting answer. A guardrail earns its place by the harm it catches, and a second growth
count catches none, so the page would carry a line that can never fire. What the son needs is to see
growth, and the count printed beside the rate already shows it.
