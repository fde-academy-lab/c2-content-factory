# Which exercise answers which of Tuesday's questions, and when is each one sat?

Tuesday teaches five topics in the curriculum's words: the one-slide answer: claim, evidence, caveat,
action; what to leave out, and the appendix; defending under challenge: restate, answer, concede, what
would change your mind; the guesstimate: clarify, map, calculate, validate; and the AI-free written
business case. Each is taught first on an invented example (Ramesh's kirana shop, Gulmohar Secondary
School, a campus canteen), then applied to the case: Uber's peak-hour earnings guarantee in Hyderabad,
one day on, where gross bookings per peak online hour fell from Rs 314 to Rs 260 at a fare that held
at Rs 165. Illustrative case: the company is real, the situation and the data are synthetic, built for
this class.

**Who needs the answer.** You, to know which set to open, when, and what each one practises.

**The questions on the way.**

- Which set goes with which chapter?
- Which topic does each item practise?
- Which work is written by hand and handed in?
- What do the labels on the items mean?
- Where are the answers?

## Where are the answers?

Every set has a solutions file of the same name in `solutions/`, opened after the set is sat. Each
lettered set's file opens on its answer letters, gives why each key holds and why each other letter
fails, and names the item worth arguing about. The written case's file holds one model page and the
checklist it passes.
