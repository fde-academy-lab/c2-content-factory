# Which exercise answers which of Tuesday's questions, and when is each one sat?

Tuesday's case is Uber's peak-hour earnings guarantee in Hyderabad, one day on. Gross bookings per
peak online hour fell from Rs 314 to Rs 260 at a fare that held at Rs 165. The city head takes the
redesign to Thursday's city review on one slide, and before the review wants a rough count of the
drivers the weekday evening peak needs. Illustrative case: the company is real, the situation and the
data are synthetic, built for this class. The sets climb the day's ladder from a title (L1) to an
interview at an AI company (L6), and the Kalpa set and the lab move the method to the programme's
client.

**Who needs the answer.** You, to know which set to open, when, and what each one practises.

**The questions on the way.**

- Which sets run in the morning studio, and which in the afternoon dojo?
- Which work is written by hand and handed in?
- Which set moves the method to Kalpa?
- What do the labels on the items mean?
- Where are the answers?

Eight of the fourteen lettered items are design calls: the denominator a slide should name, the page
an element moves to, the check that fits an estimate, the validate call on a store, and the plan that
keeps a partly right objection's true part.

## What do the labels on the items mean?

| Label | What it means |
|---|---|
| L1 to L6 | The day's ladder, from a hand count anyone can do (L1) to the depth a hard interview asks (L6) |
| Studio | The morning's practice: build a slide, present it, take an objection, get scored, rebuild |
| Dojo | The afternoon's practice: a number estimated aloud from nothing, under a clock, then checked |
| [S], [F], [D] | This programme's interview tags: [S] a staple asked everywhere, [F] frequent in GCC and product screens, [D] a differentiator that sets a strong candidate apart |
| A lettered set | A set whose items are answered with letters, posted as one line in item order |

## Where are the answers?

Every set has a solutions file of the same name in `solutions/`, opened after the set is sat. Each
lettered set's file opens on its answer letters, gives why each key holds and why each other letter
fails, and names the item worth arguing about. The written case's file holds one model page and the
checklist it passes.
