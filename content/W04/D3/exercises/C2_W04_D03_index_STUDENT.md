# Which exercise answers which question on Wednesday, and when is each sat?

Wednesday's five topics are practised first on the canteen and the kirana, both invented, then on
Swiggy Instamart's cart-page strip in Pune, whose click-through fell from 6.1 to 3.8 percent after it
began suggesting the items most often found in the same cart. Illustrative case: the company is
real, the situation and the data are synthetic, built for this class. The exercises climb the day's
ladder from a hand count (L1) to an interview question at an AI company (L6), and the Kalpa set moves
the method to the programme's client.

**Who needs the answer.** You, to know which set to open, when, and what each one practises.

**The questions on the way.**

- Which sets run in the morning, and which in the afternoon?

Sixteen of the 29 items are design calls: a best-fit choice, a sizing, the fact that would change the
call, or a second route. A sizing puts a number with its unit on each option: carts, minutes or
rupees. Each item's tag names the interview where such a question comes up; a global capability
centre is a multinational company's own technology and analytics centre in India. Each set's file
names the chapters it applies in its Applies line, so a wrong letter says which chapter to reread.

## Where are the answers?

Every set has a solutions file of the same name in `solutions/`, opened after the set is sat. Each
gives the answer letters, why each key holds and why each other letter fails, and the item worth
arguing about.
