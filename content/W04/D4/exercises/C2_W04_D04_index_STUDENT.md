# Which exercise answers which question on Thursday, and when is each sat?

Thursday's case is Zomato Gold in Chennai, where the membership dashboard reads month-two retention
flat at 38 percent while every signup cohort falls with age, and members' add-to-cart to order on
Android fell from 58 to 44 percent after a release on 14 September. Illustrative case: the company is
real, the situation and the data are synthetic, built for this class. The exercises climb the day's
ladder from a hand count (L1) to an interview call (L6), and the Kalpa set moves the method to the
programme's client.

**Who needs the answer.** You, to know which set to open, when, and what each one practises.

**The questions on the way.**

- Which sets run in the morning, and which in the afternoon?
- Which set moves the method to Kalpa, and when is it sat?
- In what order do the day's two written pages come?
- How many items ask for a design call?
- Where are the answers?

## In what order do the day's two written pages come?

Two pages are written, each with the same five lines: the call, the evidence, the cost, the
objection answered and what would change it. The first is the fix-first set's page for Zomato
Gold's membership lead, in the afternoon. In the lab, notebook 04 ends on three sentences for the TA,
which become the first lines of the second page, the Kalpa set's page for the head of Retail-Plus,
written after its items 2 to 4. The practice set comes last and asks for letters only.

## How many items ask for a design call?

Sixteen of the 28 items are design calls: a best-fit comparison, a sizing, the fact that would change
the call, or a second route. Each is marked "a design call" beside its level.

## Where are the answers?

Every set has a solutions file of the same name in `solutions/`, opened after the set is sat. Each
gives the answer letters, why each key holds and why each other letter fails, and the item worth
arguing about. The afternoon and Kalpa solutions also show what a strong page says.
