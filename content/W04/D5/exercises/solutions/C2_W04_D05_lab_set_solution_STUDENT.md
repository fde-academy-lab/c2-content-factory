# Which answers hold in the lab's practice set, and why?

Answers: 1b 2c 3a 4d 5a 6c

The six problems ran the day's method on invented shops and series: X climbs, Y repeats, Z wobbles;
the gift shop's festival-aligned forecast copies the week after last year's festival, 50; five misses

## What does the set test?

It tests the whole day on new numbers, one or more problems for each of the five topics: shape,
rules, score, judgement, code order and a miss priced in each direction.

## Why is each key right, and each other letter wrong?

| Problem | Key | Why it holds | Why the others fail |
|---|---|---|---|
| Q1, three series | b | X rises 3 a week; Y repeats 50, 50, 70, 50; Z has no steady climb and no repeat | a swaps X and Y; c calls Y's exact repeat noise; d calls Z's wobble a trend |
| Q2, the gift shop | c | This year's week 5 is the week after this year's festival; last year the week after the festival was week 4, which sold 50 | a is naive, the festival week itself; b is the same calendar week, two weeks after last year's festival; d copies an earlier week of this year |
| Q3, the MAE | a | The sizes 9, 6, 14, 3 and 4 sum to 36; over five, 7.2 | b averages the signed misses, 2.0, which is the lean, never the size; c is the sum before dividing; d is the largest single miss |
| Q4, the pitch | d | A fit says nothing about weeks the model never saw; the first question is how it scored there against the simplest copy | a and b ask how it works before whether it works; c asks for a better fit, which is the problem |
| Q5, the code order | a | Read the file, index the shipments, define the hidden weeks, score against them, print | b scores before the hidden weeks exist; c indexes a table not yet read; d cuts the hidden weeks from a series not yet built |
| Q6, the priced miss | c | The high rule wastes 1,000 spare shipments a week at Rs 5, Rs 5,000; the low rule leaves 1,000 late at Rs 30, Rs 30,000 | a reads the size and drops the direction; b swaps the two costs; d reaches for a percent, which cannot be priced at all |

## Which problem is worth arguing about?

Q3's option b. The signed misses do average 2.0, a small lean high, and a forecaster should report it.
That is a statement about direction. The MAE is a statement about size, 7.2 a week, and a plan needs
both.

## Where does the pattern live at work?

Each problem is a screen question in disguise: read a chart, forecast a holiday week, score a model,
push back on a vendor, read code, and price a miss each way. The last one is what every capacity
team, in inventory, staffing or cloud computing, does before it sizes any margin.
