# Which exercise answers which question on Friday, and which topic does each item practise?

Friday teaches five topics, the curriculum's subtopics, in four concept chapters on two invented
worlds, a chai stall at a hostel gate and a hostel mess, and then applies them to one case: Flipkart's
Lucknow fulfilment centre, where the planner must book packer shifts for the eight festive weeks
beginning 12 October to 30 November 2026, between a vendor's forecast 22 percent above last year's
and finance's rule of last year plus 4 percent. Illustrative case: the company is real, the situation
and the data are synthetic, built for this class. The exercises climb from a hand count (L1) to a
design call a hiring panel asks (L5), and the Kalpa set moves the method to the programme's client.

**Who needs the answer.** You, to know which set to open, when, and which of the five topics each
item practises.

**The questions on the way.**

- Which sets run when, and what does each practise?
- Which items practise which topic?
- Where are the answers?

## Where are the answers?

Every set has a solution file in `solutions/`, named after it with `_solution` added, opened after
the set is sat. Each gives the answer letters, why each key holds and why each other letter fails,
and the item worth arguing about.
