# Topic treatments

Pick the treatment that fits what the topic actually is. Do not repeat one
shape down the whole deck. Within any treatment the default order is
picture, then detail, then worked example.

## Structure or a set of parts
Whole first, then one slide per part.
- Picture: the whole model as a left-to-right strip or a nested containment
  diagram, each part named in a plain word
- Detail: one slide per part, each with its own example values
- Worked: the full structure filled in for one real case

## Vocabulary
- Picture: nesting or containment. System holds dataset holds record holds
  field holds value, drawn as boxes inside boxes
- Detail: a three-column table of word, what it means, example
- Rule line: which of these a question in this domain is usually about

## Choice between options
- Picture: a comparison grid, or a positioning chart on the two axes that
  actually separate the options
- Detail: what each option catches, cannot catch, and costs
- Rule: a two or three question decision tree ending on each option
- Worked: one call made out loud, with the reasoning

## Taxonomy
- Picture: a fan-out. One thing enters, N labelled things leave, each with a
  real before and after value
- Detail: a table of type, where the rule lives, what it looks like when it
  drifts
- Drill: four items, pick the type, then an answer slide with the reasoning
  per item

## Procedure
- Picture: the end-to-end flow with the decision points as diamonds
- Detail: the steps, numbered
- Worked: a step table with four columns: step number, what you do, how to do
  it, and the result of that step. Six or seven steps maximum

## Distinction people conflate
- Picture: the two things side by side with real values, each in its own
  panel, one tinted as the wrong way and one as the right way
- Detail: what each one proves and what it does not
- Rule: one line naming what must never be used as proof of the other

## Hidden failure mode
- Symptom first, with numbers that look fine
- Then the mechanism that produced it
- Then what would have caught it, and what it costs to run that check

## Judgement call with no right answer
- Two scenarios that look identical on the obvious measure and resolve
  differently on the one that matters
- Answer slide comparing them factor by factor
- The line that names which factor did the work

## Diagnosis or investigation
- Picture: the checkpoints along the path
- Detail: the decision tree, worked forward from the source rather than
  backward from the complaint
- Worked: the tree run on the case already established, one checkpoint per
  row, with match and mismatch marked

## Trade-off with no universal answer
- Two columns, both real, both with their last line naming what happens
  under pressure
- Then the factors that actually decide, four at most
- Explicitly say there is no universal correct answer

## Sizing and control
- Picture: the naive version and the controlled version side by side
- Detail: the loop, with the gate and the stop path drawn
- Worked: one full run with the decisions written out
