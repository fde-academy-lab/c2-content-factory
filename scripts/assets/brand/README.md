# Brand assets

The programme's visual identity, read by `scripts/brand.py`.

| File | Source |
|---|---|
| `bg_dark.jpg` | The dark surface of the Programme Head's academic orientation deck, version 3, 28 September 2026, saved as JPEG at quality 92 |
| `bg_light.jpg` | The light surface of the same deck, saved the same way |
| `iitgn_logo.png` | The IIT Gandhinagar mark as it appears in the same deck, at 300 pixels |

Icons are not stored here. They are Lucide icons (ISC licence, lucide.dev), rendered on first use
from the react-icons package into the build cache by `scripts/brand.py`.
